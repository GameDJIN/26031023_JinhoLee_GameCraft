## 1. 게임 개요

우주를 배경으로 한 2D 탑다운 슈팅 게임이다.
플레이어는 사격의 반동으로 우주선을 이동시키며 적을 상대한다.
공격 방향과 이동 경로를 동시에 판단하고, 마지막에 등장하는 보스를 격파하는 것이 목표이다.

이 문서는 초기 시스템 기획서이다. 아래 수치와 적 구성, 화면 경계 규칙은 구현 기준을 잡기 위한 임시안이며 이후 변경할 수 있다.
탄약 관리, 콤보, 보급소와 성장 시스템은 이번 기획 범위에서 제외한다.

## 2. 게임 상태와 진행

시작 화면 → 일반 전투 → 보스 전투 → 결과 화면

| 상태 | 처리 내용 | 전환 조건 |
| --- | --- | --- |
| 시작 화면 | 게임 제목, 조작 설명, 시작·종료 버튼 표시 | 시작 버튼 클릭 시 일반 전투 진입 |
| 일반 전투 | 플레이어 조작, 적 생성, 전투 시간 측정 | 120초 경과 시 보스 전투 진입 |
| 보스 전투 | 일반 적 생성 중지, 보스 생성 및 공격 처리 | 보스 체력 0 이하이면 클리어 |
| 결과 화면 | 성공·실패, 전투 시간, 처치 수 표시 | 다시 시작 또는 메인 화면 선택 |

- 전투 중 플레이어 체력이 0 이하가 되면 게임 오버로 결과 화면에 진입한다.
- 결과 화면에서는 이동, 공격, 적 생성과 전투 시간 측정을 중지한다.
- 다시 시작하면 체력, 위치, 속도, 시간, 처치 수와 남아 있는 적 및 공격을 모두 초기화한다.
- 같은 갱신에서 플레이어와 보스의 체력이 함께 0 이하가 되면 게임 오버를 우선한다.

## 3. 입력 시스템

| 입력 | 처리 |
| --- | --- |
| 마우스 이동 | 우주선 중심에서 커서를 향하는 조준 방향 갱신 |
| 마우스 좌측 버튼 유지 | 발사 간격마다 사격 실행 |
| 시작 화면의 종료 버튼 | 프로그램 종료 |

- 방향키 이동과 별도의 제동 키는 사용하지 않는다.
- 전투 상태에서만 조준과 사격 입력을 처리한다.
- 커서가 우주선 중심과 일치하면 직전 조준 방향을 유지한다.

## 4. 플레이어 시스템

### 4.1. 생성과 관리 정보

플레이어는 화면 중앙에서 정지한 상태로 시작하며, 최초 조준 방향은 화면 상단이다.

| 관리 정보 | 용도 |
| --- | --- |
| 위치 X, Y | 우주선 중심 위치 |
| 속도 X, Y | 현재 이동 속도 |
| 조준 방향 X, Y | 사격과 반동 계산에 사용하는 길이 1의 방향 |
| 현재 체력 | 게임 오버 판정 |
| 발사 대기 시간 | 연속 사격 간격 관리 |
| 무적 잔여 시간 | 연속 피격 방지 |

### 4.2. 반동과 관성 이동

사격이 실제로 발생할 때마다 다음 규칙으로 속도를 변경한다.

```text
속도 X = 기존 속도 X - 조준 방향 X × 반동량
속도 Y = 기존 속도 Y - 조준 방향 Y × 반동량
```

매 갱신마다 현재 속도를 위치에 반영한다.

```text
위치 X = 기존 위치 X + 속도 X × 경과 시간
위치 Y = 기존 위치 Y + 속도 Y × 경과 시간
```

- 경과 시간은 직전 갱신 이후 흐른 시간이며 초 단위로 사용한다.
- 사격하지 않아도 속도를 유지한다. 자동 감속, 정지 보정과 최고 속도 제한은 적용하지 않는다.
- 이동 방향을 향해 사격하면 속도가 상쇄되고, 계속 사격하면 반대 방향으로 이동한다.
- 비스듬한 방향의 반동은 기존 속도에 합산한다. 사격 방향으로 이동 방향을 즉시 덮어쓰지 않는다.
- 화면 경계 처리의 임시안은 반대편 연결이다. 우주선 중심이 경계를 넘으면 반대편으로 위치만 옮기고 속도는 유지한다.

### 4.3. 사격 처리

- 발사 대기 시간이 0인 상태에서 좌측 버튼을 누르면 조준 방향으로 사격한다.
- 사격 시 반동을 한 번 적용하고, 발사 대기 시간을 다시 설정한다.
- 버튼을 누른 시간이나 화면 갱신 횟수가 아니라 실제 발사 횟수에 따라 반동을 적용한다.
- 발사 대기 시간은 전투 중 경과 시간만큼 감소한다.
- 발사 대기 시간과 무적 잔여 시간은 0보다 작아지면 0으로 처리한다.
- 공격이 적에게 명중하면 해당 적의 체력을 감소시킨다. 하나의 일반 공격은 한 적에게 한 번만 피해를 준다.

### 4.4. 피격 처리

- 적의 몸체 또는 공격과 접촉하고 무적 잔여 시간이 0이면 체력을 1 감소시킨다.
- 피해를 받은 즉시 무적 시간을 설정하여, 같은 순간 여러 적과 겹쳐도 피해가 중복 적용되지 않게 한다.
- 무적 시간 동안 우주선을 깜빡이게 표시한다. 이동과 사격은 계속 가능하다.
- 피격으로 현재 이동 속도가 초기화되지는 않는다.

## 5. 적과 전투 진행 시스템

### 5.1. 일반 적 생성

- 일반 전투 진입 후 생성 주기마다 화면 가장자리의 임의 위치에 적을 생성한다.
- 생성 위치가 플레이어와 너무 가까우면 다른 위치를 선택한다.
- 동시에 존재하는 일반 적이 최대 수에 도달하면 해당 회차의 생성을 건너뛴다.
- 시간이 지나면 생성 간격을 줄인다. 기존 적의 체력과 이동 속도는 변경하지 않는다.

### 5.2. 일반 적 행동

| 종류 | 행동 | 플레이어에게 요구하는 대응 |
| --- | --- | --- |
| 추적형 | 매 갱신 시 플레이어를 향해 일정 속도로 이동 | 접근하는 적을 공격하면서 이동 경로 확보 |
| 사격형 | 생성 위치에서 주기적으로 플레이어를 조준하여 공격 | 공격 방향을 확인하고 관성과 반동으로 회피 |

- 적의 체력이 0 이하가 되면 제거하고 처치 수를 1 증가시킨다.
- 원거리 공격은 발사 순간의 플레이어 위치를 기준으로 방향을 정하며, 발사 후에는 추적하지 않는다.

### 5.3. 보스 전투

- 전투 시간 120초에 한 번만 보스를 생성한다.
- 보스 등장 시 일반 적 생성을 중지하고 기존 일반 적과 적의 공격을 제거한다.
- 보스는 화면 상단 중앙에 배치하고, 플레이어 방향을 중심으로 3방향 공격을 반복한다.
- 보스 전투 중에도 플레이어의 체력, 이동 속도와 처치 기록은 유지한다.
- 보스 체력이 0 이하가 되면 클리어로 결과 화면에 진입한다.

## 6. 충돌 판정

플레이어와 적의 몸체는 중심 위치와 반지름을 이용한 원형 판정을 사용한다.

```text
중심 간 거리의 제곱 ≤ 두 반지름 합의 제곱이면 충돌
```

그림의 투명한 여백이 아닌 실제 몸체를 기준으로 판정 크기를 설정한다.
화면 반대편으로 이동시키는 처리가 끝난 위치를 기준으로 충돌을 검사한다.

## 8. 화면 표시

- 시작 화면: 제목, 조작 설명, 게임 시작 및 종료 버튼.
- 플레이 화면: 좌측 상단 체력, 상단 중앙 전투 시간, 우측 상단 처치 수.
- 보스 전투: 기존 정보에 보스 체력 표시 추가.
- 결과 화면: 클리어 또는 게임 오버, 전투 시간, 처치 수, 다시 시작 및 메인 화면 버튼.

시작·플레이·결과의 화면 구분은 게임 상태로 처리하며, 화면마다 별도 클래스를 나누는 것을 필수로 하지 않는다.
