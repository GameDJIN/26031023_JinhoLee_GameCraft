## 게임 개요

우주를 배경으로 한 2D 탑다운 슈팅 게임이다.
플레이어는 사격의 반동으로 우주선을 이동시키며 적을 상대한다.
공격과 이동이 연결되어 있어, 발사 방향과 타이밍을 판단하는 것이 핵심이다.

## 게임 목표

몰려오는 적의 공격을 피하며 생존하고, 마지막에 등장하는 보스를 격파한다.
플레이어의 체력이 모두 소진되면 게임 오버가 된다.

## 기본 시스템

- 마우스로 조준하고 좌측 버튼으로 사격한다.
- 방향키 이동 없이 사격의 반동으로만 이동한다.
- 사격하면 발사 방향의 반대로 속도가 추가된다.
- 사격을 멈춰도 현재 속도를 유지한다.
- 이동 방향을 향해 사격하면 제동하거나 반대 방향으로 이동할 수 있다.
- 적과 접촉하거나 공격에 맞으면 체력이 감소한다.

## 기본 전투 흐름

게임 시작 → 적 등장 → 사격과 반동 이동으로 전투 및 회피 → 보스 등장 → 보스 격파 시 클리어

시간이 지날수록 적의 수와 공격 패턴을 통해 전투 난도가 높아진다.

## 게임 화면 구성

### 시작 화면

게임 제목, 조작 방법과 게임 시작 및 종료 버튼을 표시한다.

### 플레이 화면

우주선과 적의 전투를 보여주며, 플레이어 체력과 진행 시간, 보스 체력을 표시한다.

### 결과 화면

클리어 또는 게임 오버 여부와 처치 수, 진행 시간을 표시한다.
다시 시작하거나 메인 화면으로 돌아갈 수 있다.
