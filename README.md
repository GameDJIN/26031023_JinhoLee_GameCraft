# 우주 반동 슈팅

- 작성자: 이진호
- 학번: 26031023
- 개발 환경: C#, .NET 9, GLC2D

사격의 반동으로 이동하며 적을 상대하는 2D 탑다운 슈팅 게임입니다.

## 실행 방법

Windows에서 .NET 9 SDK와 Visual Studio의 .NET 데스크톱 개발 환경을 준비합니다.
`GameName.sln`을 열고 NuGet 패키지를 복원한 뒤 실행합니다.

## 파일 구성

- [게임 기획서](docs/기획서.md)
- `resource/image/`: 캐릭터, 배경, UI와 효과 이미지
- `resource/audio/`: 효과음과 배경음
- `glc2d/`: 게임 프레임워크

## 진행 상태

2주차 리소스 준비까지 완료했습니다.
현재는 기본 창만 실행되며, 화면 출력과 전투·사운드 연결은 이후 구현합니다.
