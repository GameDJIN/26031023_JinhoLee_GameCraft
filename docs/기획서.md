# 우주 반동 슈팅 게임 기획서

- 작성자: 이진호
- 학번: 26031023
- 게임 제목: 미정
- 개발 환경: C#, GLC2D

## 1. 게임 개요

우주를 배경으로 한 1인용 2D 탑다운 슈팅 게임이다.
얼굴이 보이지 않는 흰색 우주복 캐릭터가 SF 샷건의 반동으로 이동하며 적을 상대한다.
공격 방향과 이동 경로를 함께 판단하고, 마지막에 등장하는 보스를 격파하는 것이 목표이다.

## 2. 조작 방법

| 입력 | 기능 |
| --- | --- |
| 마우스 이동 | 조준 |
| 마우스 좌측 버튼 누름·유지 | 사격 |
| 메뉴 버튼 클릭 | 시작·종료·다시 시작·메인 화면 이동 |

방향키 이동과 별도의 제동 키는 사용하지 않는다.

## 3. 게임 진행

시작 화면 → 일반 적과 전투 → 120초에 보스 등장 → 보스 격파 시 클리어

플레이어 체력이 0이 되면 게임 오버가 된다.
다시 시작하면 체력, 위치, 속도, 시간, 처치 수와 남아 있는 적·공격을 초기화한다.

## 4. 기본 시스템

### 반동 이동

- 화면 중앙에서 정지한 상태로 시작한다.
- 사격할 때 발사 방향의 반대로 속도가 추가된다.
- 사격을 멈춰도 현재 속도를 유지한다.
- 이동 방향을 향해 사격하면 제동하거나 반대 방향으로 이동한다.
- 자동 감속과 최고 속도 제한은 적용하지 않는다.
- 화면 경계를 넘으면 반대편에서 나타나며 속도는 유지한다.

### 사격

- 조준 방향을 중심으로 산탄 3발을 동시에 발사한다.
- 반동과 발사음은 산탄 수와 관계없이 발사 1회당 한 번 적용한다.
- 발사체는 직선으로 이동하며, 적에게 처음 명중하거나 화면 밖으로 나가면 제거한다.
- 산탄은 각각 독립적으로 피해를 주며 적을 관통하지 않는다.
- 탄약 제한, 재장전, 무기 교체는 없다.
- 몸체와 총을 분리하여 총이 조준 방향을 향하도록 표시한다.

### 피격과 충돌

- 적의 몸체나 공격에 닿으면 체력이 1 감소한다.
- 피격 직후에는 짧은 무적 시간을 적용하고 캐릭터를 깜빡이게 표시한다.
- 무적 중에도 이동과 사격이 가능하며, 피격으로 이동 속도가 초기화되지는 않는다.
- 몸체와 발사체는 중심 위치와 반지름을 이용한 원형 충돌 판정을 사용한다.
- 이미지의 투명 여백과 총 길이는 플레이어의 몸체 판정에 포함하지 않는다.

## 5. 적 구성

| 종류 | 외형 | 행동 |
| --- | --- | --- |
| 추적형 | 초록색 둥근 외계 생물 | 플레이어를 향해 이동하고 접촉 피해를 줌 |
| 사격형 | 주황색 소형 드론 | 일정 위치에서 주기적으로 플레이어를 향해 공격 |
| 보스 | 보라색 대형 UFO형 드론 | 화면 상단 중앙에서 플레이어 방향을 중심으로 3방향 공격 |

- 일반 적은 화면 가장자리에서 등장하며, 시간이 지날수록 생성 간격이 줄어든다.
- 적의 체력과 이동 속도는 시간에 따라 증가하지 않는다.
- 일반 적은 산탄 1발에 처치되며, 처치 수를 1 증가시킨다.
- 원거리 공격은 발사 순간의 방향으로 직진하며 플레이어를 추적하지 않는다.
- 보스 등장 시 일반 적 생성을 중지하고 기존 일반 적과 적의 공격을 제거한다. 이 정리는 처치 수에 포함하지 않는다.
- 보스 전투에서도 플레이어 체력·속도와 진행 시간은 유지한다.
- 보스 체력이 0이 되면 클리어한다. 플레이어와 보스가 동시에 사망하면 게임 오버를 우선한다.

## 6. 화면 구성

### 시작 화면

게임 제목, 조작 방법과 게임 시작·게임 종료 버튼을 표시한다.
게임 종료 버튼을 선택하면 프로그램을 종료한다.

### 플레이 화면

- 좌측 상단: 체력.
- 상단 중앙: 진행 시간.
- 우측 상단: 일반 적 처치 수.
- 마우스 위치: 조준점.
- 보스 등장 시: 등장 경고와 보스 체력바.

### 결과 화면

클리어 또는 게임 오버 문구와 최종 진행 시간, 일반 적 처치 수를 표시한다.
시간과 전투 판정을 멈추고 다시 시작·메인 화면 버튼을 표시한다.

버튼은 기본·마우스 올림·눌림 상태를 구분한다.
버튼 안에서 마우스 좌측 버튼을 누른 뒤 같은 버튼 안에서 놓으면 기능을 한 번 실행한다.

## 8. 이미지와 사운드

배경은 어두운 우주이며 시작·플레이·결과 화면에서 공용으로 사용한다.
플레이어, 적과 보스는 단순하고 귀여운 도트 스타일로 제작한다.

사격 시 발사 섬광, 명중 시 불꽃, 적 처치 시 폭발 효과를 표시한다.
메뉴·일반 전투·보스 전투의 배경음을 구분하고 사격·피격·파괴·버튼 선택·결과 효과음을 사용한다.

이미지는 `resource/image/`, 사운드는 `resource/audio/`에 분리하여 보관한다.
